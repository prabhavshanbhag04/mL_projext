Performing Decision Tree Classification
A Decision Tree is a non-parametric supervised learning method used for classification and regression. The goal is to create a model that predicts the value of a target variable by learning simple decision rules inferred from the data features. We'll train a Decision Tree model and evaluate its performance.

Performing K-Nearest Neighbors (KNN) Classification

Performing Random Forest Classification
Random Forest is an ensemble learning method that operates by constructing multiple decision trees during training and outputting the mode of the classes (for classification) or mean prediction (for regression) of the individual trees. It's known for its high accuracy and ability to handle complex datasets.

Performing AdaBoost Classification
AdaBoost (Adaptive Boosting) is an ensemble learning method that trains a series of weak learners (typically decision trees) sequentially. Each subsequent learner focuses on the mistakes of the previous ones, thereby improving the overall model accuracy. We'll train an AdaBoost model and evaluate its performance.


[ ]
from sklearn.ensemble import AdaBoostClassifier
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score, confusion_matrix, classification_report

# Initialize a base learner (e.g., a shallow Decision Tree)
# Using a max_depth of 1 makes it a 'decision stump', which is common for AdaBoost
base_estimator = DecisionTreeClassifier(max_depth=1, random_state=42)

# Initialize the AdaBoostClassifier
# n_estimators: The maximum number of estimators at which boosting is terminated.
# learning_rate: Weights applied to each classifier at each boosting iteration.
adaboost_model = AdaBoostClassifier(
    estimator=base_estimator,
    n_estimators=50,
    learning_rate=1.0,
    random_state=42
)

# Train the AdaBoost model
adaboost_model.fit(X_train_scaled, y_train)

# Make predictions on the test set
y_pred_adaboost = adaboost_model.predict(X_test_scaled)

# Evaluate the AdaBoost model
print("\nAdaBoost Model Accuracy:", accuracy_score(y_test, y_pred_adaboost))

print("\nAdaBoost Confusion Matrix:")
print(confusion_matrix(y_test, y_pred_adaboost))

Removing Outliers using the Z-score Method
The Z-score measures how many standard deviations an element is from the mean. A common practice is to consider data points with a Z-score above a certain threshold (e.g., 2 or 3) as outliers. We will remove these rows from the DataFrame.


[ ]
from scipy.stats import zscore

# Create a copy of the DataFrame to perform outlier removal
df_cleaned = df.copy()

# Define a Z-score threshold
z_score_threshold = 3

rows_before_removal = df_cleaned.shape[0]
print(f"Number of rows before outlier removal: {rows_before_removal}")

# Iterate through each numeric column to remove outliers
for col in numeric_cols:
    # Calculate Z-scores for the current column, ignoring NaNs
    col_z_scores = np.abs(zscore(df_cleaned[col].dropna()))

    # Get the indices of outliers in the original column (before dropna)
    outlier_indices = df_cleaned[col].dropna()[col_z_scores > z_score_threshold].index

    # Drop rows corresponding to these outlier indices
    df_cleaned.drop(outlier_indices, inplace=True)


rows_after_removal = df_cleaned.shape[0]
print(f"Number of rows after outlier removal: {rows_after_removal}")
print(f"Number of rows removed: {rows_before_removal - rows_after_removal}")

print("\nFirst 5 rows of the DataFrame after outlier removal:")
display(df_cleaned.head())

print("\nDataFrame Info after outlier removal:")
df_cleaned.info()
